# Contributing

Thanks for considering contributing to MergePilot.

## Before opening a PR
- Explain the problem and intended behavior.
- Keep changes focused.
- Add or update tests for behavior changes.
- Run `npm run typecheck` and `npm test`.
- Never include API keys, tokens, or private repository content.

## Pull requests
- Target `develop` once the branch is established; until then, target the repository's default branch.
- Describe user-visible behavior and security implications.
- Include sample input/output when changing review behavior.

## Code of conduct
Be respectful, constructive, and focused on improving the project.
