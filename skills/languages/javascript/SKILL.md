# JavaScript Review

- Check promise rejection handling, unhandled async work, race conditions, and cancellation.
- Check coercion, equality, undefined/null handling, and mutation of shared objects.
- Review event listener cleanup, timers, subscriptions, and browser resource lifecycles.
- For Node.js, inspect stream backpressure, filesystem paths, process lifecycle, and error propagation.
- For browser code, inspect DOM assumptions, storage access, cross-origin boundaries, and event cleanup.
- Do not assume browser or Node.js APIs are available without checking the project runtime.
