# Dart Review

- Check sound null safety, nullable flows, late initialization, casts, and force unwraps.
- Inspect Future/Stream error propagation, unawaited futures, cancellation, and concurrency assumptions.
- Check isolate boundaries and message serialization when isolates are used.
- Review collection mutation, equality, immutability, and async state updates.
- Check resource disposal for streams, subscriptions, timers, controllers, and clients.
- Consider supported Dart SDK constraints and package API compatibility before flagging language features.
